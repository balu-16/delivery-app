Inventory uses integer decimal strings for the smallest individually saleable unit of each variant; a case is converted to units before receipt. Different package sizes are different variants. Stock originates from receipt or a QC-approved return. A manager’s physical cycle count may also reconcile a surplus against an existing received batch, with the same immutable audit and variance approval rules as shortages; there is no arbitrary public balance setter.

Every on-hand or reservation change records an immutable ledger entry in the same transaction. Aggregate inventory and batch totals must reconcile. Reservation locks are ordered by store and variant, then by FEFO batch; committed reservations do not expire. Batch eligibility is evaluated at the requested delivery time plus the category's configured minimum remaining shelf life. No order table is invented before P6.
